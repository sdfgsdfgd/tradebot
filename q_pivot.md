more likely to be a durable pivot than a recoil, without merely moving the
existing signal earlier and increasing noise.

## 3. The Multiscale Phase-Front Pivot

For direction-normalized horizon `h`:

```text
S_h(t) = causal slope at horizon h
V_h(t) = S_h(t) - S_h(t-1)
A_h(t) = V_h(t) - V_h(t-1)
J_h(t) = A_h(t) - A_h(t-1)
```

When incumbent slope and new velocity oppose each other, record the diagnostic
zero-cross estimate:

```text
eta_h(t) = -S_h(t) / V_h(t), when S_h and V_h have opposite signs
```

`eta` never promises a future price. Its useful information is whether several
crossing estimates contract coherently, in causal fast-to-slow order, and
remain contracted after recoil.

For each horizon record:

- `tau_v(h)`: first persistent new-direction velocity flip;
- `tau_s(h)`: first subsequent slope zero-cross;
- velocity-front order, gaps, breadth, persistence, relapse, and acceleration;
- slope-front order, gaps, breadth, persistence, and recross;
- distance between velocity and slope fronts and whether it contracts;
- first recoil, maximum recoil, survival, and renewed fast reacceleration;
- SPY cash discovery versus normalized UPRO/inverse-SPXU acceptance;
- ES context only when its source and timestamp are native/causal—current
  delayed type-3 ES is not live evidence;
- ATR/TR, volume, quote intensity, spread, imbalance, same-price pressure,
  divergence, reconvergence, and first-move order;
- existing daily `5/10/21/42/63/84` phase and completed 4h/weekly context;
- news pressure, delta, velocity, confidence, freshness, and publication time.

### 3.1 Categorical state machine

The state machine is symmetric for DOWN→UP and UP→DOWN.

| Phase | Required causal anatomy | Authority during discovery |
|---|---|---|
| `INCUMBENT` | Existing direction still owns the slope stack | Observe |
| `REPAIR_SPARK` | Seconds/5m/15m velocity turns against still-incumbent slow slopes | Attention only |
| `FRONT_PROPAGATING` | New velocity persists and reaches progressively slower clocks in an ordered path | Candidate |
| `CROSS_CONVERGING` | Several valid `eta_h` contract without fast-front relapse | Candidate |
| `FAST_SLOPE_CROSS` | Seconds/5m/15m slopes cross while slow velocities continue repairing | Candidate |
| `RECOIL_TEST` | First pullback tests the new front without destroying repaired slow velocity | Candidate |
| `REACCELERATION` | Seconds flow/velocity re-ignites and SPY→ETF transport accepts | Candidate |
| `SLOW_SLOPE_CASCADE` | 30m→60m→120m slopes cross in causal order; slower clocks continue converging | Candidate |

| `RELAPSED` | Fast velocity fails before ordered propagation/cross/recoil survival | Revoke candidate |
| `HANDOFF` | Exceptional opposite shock establishes explicit new authority before ordinary propagation completes | Separate shock state |
| `NORMALIZED` | Front loses energy without an opposite owner | Flat/release, never invent direction |

### 3.2 Later action vocabulary

The derived owner may eventually emit only:

- `WAIT`: spark exists; propagation unproved;
- `ADMIT_EARLY`: ordered propagation + contracting crossings + transport
  acceptance survive, before all slopes cross;
- `ADMIT_CONFIRMED`: fast cross + first recoil survival + reacceleration;
- `REVOKE`: the front relapses or transport refuses before entry;
- `HANDOFF`: an independently proven opposite shock owns direction;
- `FLAT`: no causal owner.

During count/morphology phases these are labels only. They have no live effect.
